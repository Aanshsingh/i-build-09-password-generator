# 🔐 Password Generator — I BUILD #09/80

A customizable and responsive Password Generator built using HTML, CSS, and JavaScript.

The application allows users to generate passwords based on their preferred length and character types.

## ✨ Features

- 🔢 Custom password length
- 🔠 Uppercase characters
- 🔡 Lowercase characters
- 🔢 Numbers
- 🔣 Symbols
- ⚡ Dynamic password generation
- 🎛️ Interactive settings
- 📱 Responsive design
- 🎨 Modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation

## 🧠 What I Learned

- DOM manipulation
- Event listeners
- Random number generation
- String manipulation
- Character sets
- Conditional statements
- User input handling
- Dynamic UI updates
- Responsive design

## ⚙️ How It Works

The user can choose:

- Password length
- Uppercase characters
- Lowercase characters
- Numbers
- Symbols

JavaScript then builds a character set based on the selected options and randomly generates a password.
